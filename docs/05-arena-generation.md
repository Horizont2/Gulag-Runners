# 05 — Генерація арен

## Вимоги

- Арена **повністю детермінована з 64-бітного сіду**. Обидва клієнти будують ідентичний світ
  без жодного трафіку на геометрію.
- Ширина: **3 екрани** (≈ 54 метри геймплейної площини). Висота: 3 рівні платформ.
- Збирається за < 300 мс на телефоні середнього класу.
- Гарантовано проходима: кожна скриня досяжна без зброї мобільності.

## Модульна сітка (не шумова генерація)

Арена = **9 модулів 6×3 метри** у сітці 3 (довжина) × 3 (висота), плюс обрамлення.
Кожен модуль — вручну зроблена Unity-префаб-кімната з позначеними сокетами.

```
┌────────┬────────┬────────┐  верхній ярус (дахи, гілки, труби)
│  A3    │  B3    │  C3    │
├────────┼────────┼────────┤  середній ярус (платформи, мости)
│  A2    │  B2    │  C2    │
├────────┼────────┼────────┤  нижній ярус (земля, вода, провалля)
│  A1    │  B1    │  C1    │
└────────┴────────┴────────┘
   СПАВН 1   ЦЕНТР   СПАВН 2
   (сітка)            (сітка)
```

**Чому модулі, а не процедурний шум:** у файтингу геометрія — це баланс. Процедурний шум
дає непрохідні кишені, нечесні висоти й «камперські» кути. Модулі дають варіативність
(9 слотів × 6–10 варіантів кожен = мільйони компоновок), але кожен модуль протестований руками.

### Правила збірки

1. Колонки A і C — **дзеркальні за топологією**: якщо A2 має 2 платформи й 1 шафку,
   C2 теж має 2 платформи й 1 шафку (інші візуали, інша форма, той самий бюджет).
   Це єдине, що робить матч чесним.
2. Колонка B (центр) — **асиметрична і завжди найцікавіша**: вертикальна арена,
   центральна скриня, головний хазард.
3. Кожна арена має рівно: **1 хазард-зону**, **1 вертикальний шорткат** (драбина/ліана/ліфт),
   **1 «кільце»** — замкнений маршрут, щоб можна було кайтити й не загнатись у тупик.
4. **Правило кута зору:** з будь-якої точки геймплейної площини видно щонайменше 40%
   поточного екрана без перекриття. Валідується автоматичним тестом на етапі збірки.

### Валідатор (CI-тест)

Кожна згенерована арена проганяється автоматично:
- [ ] усі скрині досяжні з обох спавнів (pathfinding-агент без зброї);
- [ ] жодної «пастки без виходу» (вузол, з якого нема двох різних шляхів);
- [ ] бюджет луту половин відрізняється ≤ 10%;
- [ ] час перебіжки спавн → центр: 3.2–4.0 сек з обох боків (±0.3 сек між гравцями);
- [ ] нема перекриття геймплейної площини декораціями переднього плану > 20%.

Генератор, який не пройшов валідатор, перекидає сід. Це дешево й ловить 99% поганих арен.

## Хазарди (по одному на арену)

| Біом | Хазард | Поведінка |
|---|---|---|
| Ліс | падаюче дерево | скидається від удару, перекриває маршрут на 10 сек |
| Печера | провал у воду | нокаут при падінні, повернення через 3 сек з −15 HP |
| Завод | конвеєр + прес | штовхає; прес бʼє 40 шкоди за розкладом (2 сек тел) |
| Болото | зона трясовини | −60% швидкості, рух видає бульки (чутно) |
| Станція | потяг | раз за 20 сек, проїзд по нижньому ярусу, 2.5 сек сирена-попередження |
| Кар'єр | парові гейзери | підкидають обох угору — інструмент, не лише загроза |

**Правило:** хазард мусить бути **використовуваним**, не лише карати. Найкращий хазард —
той, в який можна кинути суперника захватом.

## Динаміка арени в часі

- 0:22 — електрична сітка в центрі опускається в підлогу.
- 0:35 — авіаскид падає в напіввипадкову точку центру.
- 0:45 — паркан починає підбирати краї, по 2 м кожні 5 сек.
- 1:00 — залишається тільки центральна колонка B.

Арена фізично звужується → матч не може тягнутись. Це рятує мобільну сесію від затягування.

## Біоми в релізі

| № | Біом | Настрій | Фішка геометрії |
|---|---|---|---|
| 1 | **Тайговий ліс / лісоповал** | сіро-зелений, туман, ранок | гілки = верхній ярус, гак-кішка |
| 2 | **Шахта / вапнякова печера** | темно, точкове світло | реальна темрява, світло як ресурс |
| 3 | **Барачна зона / двір** | сніг, прожектори, колючка | відкритий простір, мало укриттів, башти |
| 4 | **Збагачувальний завод** | іржа, пар, жовте світло | багато вертикалі, труби, конвеєри |
| 5 | **Затоплене болото / село** | буро-зелений, мряка | вода змінює швидкість, містки |
| 6 | **Мерзла залізнична станція** | синьо-білий, ніч | вагони як платформи, потяг-хазард |
| 7 | **Сірчаний кар'єр** | жовто-чорний, спека | гейзери, рухомі платформи |
| 8 | **Бункер / метро-тунель** | бетон, аварійне світло | тісно, бій на короткій дистанції |

Кожен біом = один набір модулів + одна палітра + 1–2 унікальні T3-предмети + 1 хазард.
**MVP: тільки біом 1.**

## Що бачить гравець на екрані вибору

Нічого. Арена **не вибирається** — вона рандомна, і це частина ядра («випадкові арени»).
Але після матчу показується «ти грав на: Лісоповал #4821» — сід можна зберегти в улюблені
й зіграти на ньому приватний матч з другом.
