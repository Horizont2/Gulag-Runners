# 05 — Генерація арен (смугова топологія)

## Вимоги

- Арена **детермінована з 64-бітного сіду** — обидва клієнти будують ідентичний світ
  без жодного трафіку на геометрію.
- Мусить підтримувати **фог-ов-вор**: має існувати багато місць, звідки гравці фізично
  не бачать одне одного.
- Збирається < 300 мс на телефоні середнього класу.
- Гарантовано проходима без предметів мобільності.

## Топологія: смуги й кімнати

Арена — це **розріз будівлі/печери збоку**, 3 поверхи × 3 крила:

```
        КРИЛО A (спавн 1)      ЦЕНТР B           КРИЛО C (спавн 2)
       ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
ПОВ. 3 │     A3       │═══│      B3      │═══│     C3       │   дахи, балки, відкрите небо
       ├──────┬───────┤   ├──────────────┤   ├───────┬──────┤
ПОВ. 2 │  A2a │  A2b  │═══│  ЦЕНТР.ЗАЛА  │═══│  C2b  │ C2a  │   кімнати, коридори
       ├──────┴───────┤   │   (золота    │   ├───────┴──────┤
ПОВ. 1 │  🔒 КЛІТКА 1 │═══│    скриня)   │═══│ КЛІТКА 2 🔒  │   підвал, вода, тунелі
       └──────────────┘   └──────────────┘   └──────────────┘
          ═══ = драбини, люки, двері, пролами
```

**Дві «смуги глибини»** додатково: кожна кімната має задній відсік (−3 м по Z), куди можна
зайти через двері. Камера зміщується, бій усе одно лишається на одній площині.
Це дає схованки без втрати читабельності бою.

**Чому це вирішує фог-ов-вор:** з 11 ігрових просторів у типовій арені з будь-якої точки
видно 1–2. Суперник за стіною — це справді суперник, якого не видно, рівно як у нотатці Miro.

## Модульна збірка, не шумова генерація

Кожна комірка сітки — **вручну зроблений Unity-префаб** із сокетами по краях.
9 комірок × 6–10 варіантів = мільйони компоновок із протестованих деталей.

> **Чому не процедурний шум:** у файтингу геометрія — це баланс. Шум дає непрохідні кишені,
> нечесні висоти й камперські кути. Модулі дають варіативність **без** цих ризиків.

### Правила збірки

1. Крила A і C — **дзеркальні за топологією**: однакова кількість кімнат, скринь, драбин і
   виходів. Різні візуали, різний вміст, **однаковий бюджет** ([03](03-loot-and-chests.md)).
2. Центр B — **асиметричний і завжди найцікавіший**: вертикальна зала, золота скриня,
   головний хазард, усі шляхи сходяться.
3. Кожна арена містить рівно: 1 хазард-зону, 2 вертикальні шорткати, 1 «кільце»
   (замкнений маршрут, щоб можна було кайтити й не загнатись у тупик).
4. **Правило двох виходів:** будь-яка кімната має ≥ 2 виходи. Кімната з одним виходом —
   смертельна пастка в грі, де суперника не видно.
5. **Акустична зв'язність:** кожна кімната має ≥ 1 «звукового сусіда» — кімнату, звуки з якої
   чути приглушено. Це проєктується руками, бо це і є фаза «Падальщик».

### Валідатор (тест у CI)

Кожен згенерований сід проганяється автоматично; не пройшов — сід перекидається:

- [ ] усі скрині досяжні з обох кліток (pathfinding без предметів мобільності);
- [ ] у кожної кімнати ≥ 2 виходи;
- [ ] бюджет луту крил відрізняється ≤ 10%;
- [ ] час клітка → центральна зала: 7–9 сек з обох боків, різниця ≤ 0.5 сек;
- [ ] кожна кімната має акустичного сусіда;
- [ ] з будь-якої точки видно ≤ 2 ігрових простори (інакше фог-ов-вор зламаний);
- [ ] передній план не перекриває площину бою > 20%.

## Хазарди (один на арену, мусить бути **використовуваним**)

| Біом | Хазард | Поведінка |
|---|---|---|
| Ліс | падаюче дерево | збивається ударом, перекриває маршрут на 10 сек |
| Печера | провал у воду | нокдаун, повернення через 3 сек з −15 HP |
| Завод | конвеєр + прес | штовхає; прес б'є 40 за розкладом (2 сек тел) |
| Болото | трясовина | −60% швидкості, рух видає бульки (**чутно!**) |
| Станція | потяг на нижньому поверсі | раз на 20 сек, 2.5 сек сирена-попередження |
| Кар'єр | парові гейзери | підкидають угору — інструмент, не лише загроза |
| Фортеця | підйомна решітка | падає, ділить кімнату навпіл |

Найкращий хазард — той, у який можна **кинути суперника захватом**.

## Динаміка арени в часі

- 0:03 — клітки відчиняються.
- 0:25 — відчиняється центральна зала + радар-імпульс.
- 0:40 — у центральну залу падає клітка з припасами.
- 1:15 — **сталеві заслінки** з гуркотом замикають крайні кімнати по одній кожні 8 сек.
- 2:00 — залишається тільки центральна зала.
- 2:20 — стеля падає, раптова смерть.

Арена фізично звужується → матч не може тягнутись, мобільна сесія лишається короткою.

## Біоми в релізі

| № | Біом | Режим | Фішка геометрії |
|---|---|---|---|
| 1 | **Тайговий лісоповал** ⭐ MVP | середньовічний | гілки = верхній поверх, гак-кішка, відкрите небо + скайбокс |
| 2 | **Шахта / вапнякова печера** | обидва | справжня темрява, світло як ресурс |
| 3 | **Руїни фортеці** | середньовічний | підйомні решітки, вузькі сходи, донжон у центрі |
| 4 | **Затоплене болото / село** | середньовічний | вода змінює швидкість і шумить, містки |
| 5 | **Барачна зона / двір** | вогнепальний | відкрито, довгі лінії вогню, вишки |
| 6 | **Збагачувальний завод** | вогнепальний | багато вертикалі, труби, конвеєри |
| 7 | **Мерзла залізнична станція** | вогнепальний | вагони як кімнати, потяг-хазард |
| 8 | **Бункер / тунель метро** | вогнепальний | тісно, бій накоротко, нуль довгих ліній |

Кожен біом = набір модулів + палітра + скайбокс + 1–2 унікальні T3-предмети + 1 хазард.
**MVP: тільки біом 1.**

## Вибір арени

Арена **не вибирається** — вона рандомна, це частина ядра. Після матчу показується
`Лісоповал #4821`, сід можна зберегти й зіграти приватний матч із другом на тій самій арені.
