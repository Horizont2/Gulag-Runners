# 02 — Камера, бій, керування

## Рішення №1: камера. «top/side» → смугова арена

У нотатці з Miro: *«camera from top/side»* — тобто питання ще відкрите. Це рішення
каскадує на все інше, тому розбираю три варіанти:

| Варіант | Плюси | Мінуси |
|---|---|---|
| **A. Строго збоку, одна площина** | Найкраще відчуття бою, ідеальна читабельність на 6", найдешевший неткод | Дослідження пласке; «не бачити суперника» майже неможливо — видно всю смугу |
| **B. Вільний 3D, камера згори-збоку** | Справжнє дослідження, фог-ов-вор природний | Бій на телефоні читається погано, стрільба вимагає сильного автоприцілу, дорожче в усьому |
| **C. ⭐ Смугова арена (гібрид)** | Бій **завжди** на одній площині збоку (читабельність A), але арена — це **кілька з'єднаних смуг/кімнат** по вертикалі й глибині. Фог-ов-вор справжній | Трохи складніша камера й навігація |

**Рекомендація — C.** Арена як **розріз будівлі/печери**: кілька поверхів, кімнати,
бокові відсіки, з'єднані драбинами, дверима й люками. Камера завжди дивиться збоку на
ту смугу, де ти зараз, з легким нахилом згори (~12°) — звідси й «top/side» з нотатки.

Чому саме так:
- твій референс зі стік-менами («Refreshing Shooting Experience») — це рівно така
  смугова стрільба збоку, і вона явно читабельна;
- коли двоє в різних кімнатах — вони **фізично не бачать одне одного**, як і написано в нотатці;
- коли зустрілись — це чистий файтинг на одній лінії, без промахів «по глибині»;
- low-poly арени з літаючих руїн (другий референс) добре лягають на такі смуги з відкритим
  небом і скайбоксом.

### Правила камери

- Перспектива, вузький FOV ~30°, нахил згори 10–14° — об'єм видно, спотворення нема.
- **Висота персонажа = 17–20% висоти екрана.** Менше — не читається на телефоні.
- Коли обидва в одній смузі — камера тримає двох у кадрі, зум у межах 60–110%.
- Коли сам — камера трохи попереду за напрямком руху (lookahead 1.5 м).
- Перехід між смугами — **швидкий зріз із 0.15 сек розмиттям**, не плавний політ
  (плавний політ = втрата контролю в бою).
- Передній план ніколи не перекриває площину бою більше ніж на 20% і прозорішає в зоні бою.
- Під час загадки камера **не блокується і не наближається повністю** — тебе мусять могти вдарити.

## Рішення №2: два режими бою

| | **Середньовічний** | **Вогнепальний** |
|---|---|---|
| Кнопка **БЛОК** | є | **нема** |
| Кнопка **УХИЛ/ПЕРЕКАТ** | нема (блок замінює) | є |
| Атака | тап = легкий, утримання = важкий | тап = постріл, утримання = черга/приціл |
| Приціл | автоповорот до суперника | автоповорот + м'який автоприцілу по висоті (на телефоні без нього гра неграбельна) |
| Броня | гасить відсоток шкоди | гасить фіксоване число |
| Ключова навичка | таймінг парирування | позиція й укриття |

**Блок/парирування (Середньовічний):**
- утримання = блок, гасить 70% шкоди, витрачає стаміну, ламається від важких ударів;
- тап **за 0.2 сек до удару** = парирування: нуль шкоди + суперник у стані вразливості 0.8 сек.
  Це головний скіловий потолок режиму.

**Чому блок не потрібен у вогнепальному:** блокувати кулю нема чим (щити — не в тій фантазії),
а головна оборонна дія — **розірвати лінію вогню**: перекат, стрибок на інший поверх,
зайти за укриття. Нотатка з дошки має рацію, і це вже перевірений дизайн.

## Кулаки / безоружний бій

Обидва режими починаються з голих рук, тож безоружний бій мусить бути життєздатним:

| Властивість | Кулаки | Зброя |
|---|---|---|
| Вікно замаху | 3 кадри (найшвидше в грі) | 7–14 кадрів |
| Шкода | 6 | 12–26 (мілі) / 8–20 за постріл |
| Захват і кидок | **Так** | Ні |
| Ресурс | безкінечний | міцність / патрони |
| Відкрити скриню | 6 сек, тихо-ish | 2 сек, **дуже гучно** |
| Відчай | **+40% шкоди нижче 30% HP** | — |

**Захват** — єдине, що карає спам важкою зброєю: схопив і кинув у стіну / у хазард / з поверху.

## Слоти

Три слоти, нуль меню:

```
[ ЗБРОЯ ]   [ БРОНЯ ]   [ УТИЛІТА ]
```

Броня піднята в окремий слот згідно з нотаткою («armor, melee or guns»). Броня **видима на
персонажі** — суперник бачить, що ти в латах, і це важлива тактична інформація, яку дає
сам силует.

Підняв нове — старе падає. Нема інвентаря, нема іконок у сітці, нема екрана спорядження.

## Керування

Залишаю схему з Miro (1 джойстик + атака + стрибок) і додаю четверту контекстну кнопку.

### Середньовічний
```
┌──────────────────────────────────────────────────────────────┐
│  ███████░░ HP   🛡️                0:38             HP ░░████  │
│                                                              │
│      ╔═══╗                                       ( АТАКА )   │
│      ║ ⊙ ║  джойстик                      (ДІЯ)  ( БЛОК )    │
│      ╚═══╝  вгору = стрибок                      ( ⤒ )       │
└──────────────────────────────────────────────────────────────┘
```

### Вогнепальний
```
                                                  ( ВОГОНЬ )
                                           (ДІЯ)  ( ПЕРЕКАТ )
                                                  ( ⤒ )
```

- **ДІЯ** — контекстна: підняти / відкрити скриню / кинути (утримання) / **захват** (коли
  суперник впритул) / пролізти в люк. Іконка на кнопці показує поточний контекст.
- **⤒** — стрибок, маленька кнопка, як і в нотатці. Вона ж «піднятись драбиною» при утриманні.
- Усе інше автоматично: автоповорот, автопідбір при проході над лутом (якщо слот вільний),
  ledge assist (ніхто не падає через товщину пальця), м'який автоприціл у вогнепальному.

### Обов'язкові налаштування
Розмір/позиція кнопок, ліворукість, вібровідгук, вимкнення тряски камери,
**напрямний індикатор звуку** (для гри без звуку й для глухих — не опція, а дефолт),
режим дальтонізму.

## Бойові числа (стартові для тюнінгу)

- HP 100, броня T1/T2/T3 = −15% / −30% / −45% вхідної шкоди.
- Цільовий TTK: **8–14 сек** активного бою.
- Стаміна: 3 заряди, відновлення 1.2 сек; витрачається на перекат, біг, тримання блоку.
- Комбо максимум 3 удари (легкий-легкий-важкий). Довші комбо на телефоні = фрустрація.
- Хітстан, відкид, відбій від стін, добивання хазардами й падінням з поверхів.

## Читабельність (критично для low poly на 6")

- Гравець 1 — **холодний** акцент (cyan), Гравець 2 — **теплий** (orange). Колір видно
  навіть у чистому силуеті.
- Rim light на обох завжди, навіть на темному фоні.
- Фон десатурований, усе інтерактивне — насичене + світиться за тіром.
- Зброя зчитується **за формою силуету**: довге / коротке / важке / метальне / ствол.
- Нуль чисел у бою. Шкода — хітстоп, тряска, частинки.
- **HUD мінімальний.** Референс покрокової RPG з дошки — приклад того, чого робити не можна:
  там 40 елементів інтерфейсу, у нас їх максимум 8.
