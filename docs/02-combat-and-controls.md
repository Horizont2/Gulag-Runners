# 02 — Бій, керування, камера

## Вимір: 3D-графіка, 2D-правила

Світ, персонажі й анімації — повноцінне 3D. Але **геймплейна площина — одна**: обидва бійці
стоять на спільній площині XY, як у файтингу. Глибина (Z) використовується тільки для
візуалу: шари паралаксу, об'єм декорацій, камера з легкою перспективою.

**Чому не вільний рух по Z.** На 6-дюймовому екрані гравець не може точно оцінити, чи
суперник стоїть у тій самій «дорожці». Вільний Z = промахи, які читаються як баги.
Один виняток, який дає відчуття 3D без втрати читабельності:

> **Ухил у глибину (Dodge Back).** Свайп вниз/назад — персонаж фізично відстрибує
> на задній план, ~0.35 сек невразливості, і повертається. Виглядає як 3D-маневр,
> працює як чистий dodge-frame у файтингу.

## Кулаки — ядро бою

Кулаки мусять бути **життєздатні**, інакше вся перша фаза матчу = «хто швидше знайшов зброю, той виграв».

| Властивість | Кулаки | Зброя |
|---|---|---|
| Вікно замаху | 3 кадри (найшвидше в грі) | 7–14 кадрів |
| Шкода | 6 | 12–26 |
| Парирування | **Так** (кулаками можна відбити удар) | Ні (крім «щитових» предметів) |
| Захват і кидок | **Так** | Ні |
| Ресурс | Безкінечний | Міцність / заряди |
| Відкриття скрині | Повільно (6 сек) | Швидко (2 сек, −міцність) |

Плюс дві механіки:
- **Відчай.** Нижче 30% HP кулаки дають +40% шкоди. Підкреслює фантазію «загнаний у кут втікач».
- **Захват.** Кулаками можна схопити суперника і кинути — у стіну, в пастку, з платформи.
  Це єдиний спосіб покарати того, хто «заспамив» важкою зброєю.

## Зброя як витратний ресурс

Один слот зброї + один слот утиліти. Підняв нове — старе падає на землю (можна підняти назад,
можна кинути в суперника). Жодних інвентарів і меню.

Міцність/заряди показані **кільцем навколо кнопки атаки**. Коли ресурс добігає, кільце червоне
й персонаж починає тримати зброю інакше (візуальний тел для суперника — він бачить, що ти на нулі).

**Ключова напруга:** зброя — це й твій «лом». Витратив заряди на дві скрині — зустрічаєш
суперника з кулаками й чужою аптечкою.

## Бойова система

- **HP:** 100. **Цільовий TTK:** 8–14 сек активного бою.
- **Хітстан і відкид**, відбій від стін (геометрія арени має значення), добивання об хазарди
  й падіння з платформ (environmental kills — найвиразніші моменти для клипів).
- **Три висоти атак:** низька (підсічка), середня, стрибкова. Блок працює проти середньої,
  присід — проти високої. Мінімальна, але реальна «гра в камінь-ножиці».
- **Стаміна** тільки на ухил і біг (3 заряди, відновлення 1.2 сек) — щоб ухил не спамили.
- **Нема комбо-довжин більше 3 ударів.** На телефоні довгі комбо = фрустрація. Максимум:
  легкий-легкий-важкий.

## Керування

### Основна схема (landscape, два пальці)

```
┌──────────────────────────────────────────────────────────────┐
│  HP ████████░░            0:38  ⚡RD 2       ░░░░████ HP     │
│                                                              │
│                                                              │
│      ╔═══╗                                         ( АТАКА ) │
│      ║ ⊙ ║  ← віртуальний стік               (ВЗЯТИ) (УХИЛ)  │
│      ╚═══╝       (вгору = стрибок)                           │
│                  (вниз  = присід)                            │
└──────────────────────────────────────────────────────────────┘
```

Три кнопки, не більше:
- **АТАКА** — тап = легкий, утримання = важкий; та сама кнопка ламає скрині.
- **УХИЛ** — ухил у глибину; у повітрі = швидке падіння.
- **ВЗЯТИ / ДІЯ** — контекстна: підняти, відкрити скриню, кинути предмет (утримання), захват
  (коли суперник поруч). Контекст підсвічується іконкою на самій кнопці.

Усе інше — автоматика: автоповорот до суперника, автопідбір при проході над лутом
(якщо слот вільний), авто-підлаштування під край платформи (ledge assist), щоб ніхто не
падав через товщину пальця.

### Компактний режим (portrait, один палець)

Для гри в транспорті. Камера вужча, арена скролиться. Керування:
- тап по лівій/правій половині екрана — рух у бік,
- тап по суперникові — атака,
- свайп вниз — ухил, свайп вгору — стрибок,
- тап по скрині — почати відкриття.

Портретний режим має **невелику автоматичну поблажливість** (ширше вікно парирування),
і матчмейкінг **не** розділяє режими — інакше вбиваємо ліквідність пулу.

### Обов'язкові налаштування
Розмір і положення кнопок, ліворукість, «тільки тапи без стіка» (кнопки ←/→),
вібровідгук on/off, вимкнення тряски камери.

## Камера

- Перспективна, вузький FOV (~28°), майже ортографія — щоб бійці не деформувались на краях.
- **Висота персонажа = 17–20% висоти екрана.** Менше — не читається на телефоні.
- Камера тримає обох гравців у кадрі з плавним зумом; жорсткі межі по зуму
  (мін. 60%, макс. 110%), щоб силуети не ставали мікроскопічними.
- У момент загадки камера **не блокується** і **не наближається повністю** — суперник
  мусить залишатись видимим периферійно, інакше загадка перетворюється на безпечний
  «вийшов з гри» таймаут.
- Шари глибини: 1) фон-небо, 2) далекий силует, 3) середній план, 4) **геймплейна площина**,
  5) передній план (стовпи, гілки, іскри). Передній план ніколи не перекриває бійців більше
  ніж на 20% і завжди напівпрозорий у зоні бою.

## Читабельність (найважливіше для вигляду збоку на телефоні)

- Персонажі: **контрастні силуети**, обведення (rim light) завжди, навіть на темному фоні.
  Гравець 1 — холодний акцент, Гравець 2 — теплий. Колір видно навіть у силуеті.
- Фон — десатурований. Усе, з чим можна взаємодіяти — **насичене + світиться** за тіром луту.
- Зброя зчитується **за формою силуету**, не за текстурою: довге/коротке/важке/метальне.
- Жодних чисел у бою. Шкода — тільки відчуттям: хітстоп, тряска, частинки.
