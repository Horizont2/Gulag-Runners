# 07 — Етапи, ризики, монетизація

## Етапи

### M0 — Прототип ядра (2–3 тижні), без власної графіки

Мета: перевірити **єдину гіпотезу** — чи цікаво 22 секунди шукати лут, не бачачи суперника.

Беремо прямо з дошки Miro:
| Потреба | Пакет |
|---|---|
| Персонажі | `Free Pack — Stick Man 3D Characters` |
| Анімації мілі | `32 RPG Animations (FREE)` |
| Зброя | `Low Poly Weapons VOL.1`, `Low Poly FPS Weapons Lite` |
| Небо | `Stylized Skyboxes (FREE)` |
| Арена | сірі бокси руками |

- [ ] Детермінована симуляція на fixed-point, 60 Гц
- [ ] Рух, стрибок, атака, **блок/парирування** (середньовічний режим)
- [ ] Смугова арена з 6 кімнат + драбини/люки, камера з переходами між смугами
- [ ] 2 предмети зброї + 1 броня, з ресурсом
- [ ] 2 типи скринь (ящик, сейф) + 2 загадки
- [ ] **Система звуку з гучністю як частиною стану** + напрямний індикатор на екрані
- [ ] Один пристрій, split-input (неткоду ще нема)

**Питання, на яке мусить відповісти M0:** чи напружена фаза наосліп, чи просто порожня?
Якщо порожня — вмикаємо запасні важелі з [01](01-concept.md): коротша фаза (15 сек),
ранній радар-імпульс, більше звукових подій.

### M1 — Вертикальний зріз (6–8 тижнів)

Один біом (Лісоповал), середньовічний режим, справжній low-poly арт.
- [ ] Rollback-неткод, 2 телефони через релей
- [ ] Повний цикл матчу: клітки → падальщик → сирена → полювання → стулення
- [ ] 10 предметів (зброя/броня/утиліта), 5 типів скринь, 6 загадок
- [ ] Генератор арен із сіду + валідатор у CI
- [ ] Керування landscape + компактний portrait

**Критерій виходу:** 20 зовнішніх гравців × 10 матчів. Метрики: тривалість матчу 1:40–2:30,
win rate vs бюджет луту в межах 50 ± 6%, ≥ 60% кажуть «хочу ще раз», і — найважливіше —
≥ 50% описують фазу наосліп словами «напружено», а не «нудно».

### M2 — Другий режим і контент (3 міс)
Вогнепальний режим (автоприціл, укриття, лут-таблиця), 4 біоми, 14 предметів на режим,
10 загадок, **золото + ліги + боти для новачків** ([09](09-economy-and-ranking.md)), косметика.

### M3 — Софт-лонч (1 регіон)
Телеметрія, тюнінг балансу, LiveOps, сезон 0, анти-смурф.

## Ризики і що з ними робити

| Ризик | Серйозність | Мітигація |
|---|---|---|
| **Фаза наосліп нудна** — нема з ким взаємодіяти 22 сек | 🔴 висока | Драбина інформації (звук → сліди → промені → пік → радар). Головне питання M0. Запасні важелі описані в [01](01-concept.md) |
| **Рандом луту = несправедливо** | 🔴 висока | Дзеркальна топологія + бюджет ±10% + гарантований мінімум на крило + телеметрія win-rate. Це вимірювана річ, не питання смаку |
| **Смугова камера плутає гравця** («де я, куди йти») | 🟠 середня | Мінімапа-розріз у кутку (показує **тільки відвідані** кімнати), швидкі зрізи замість польотів, різні палітри поверхів |
| **Два режими = подвійний обсяг роботи** | 🟠 середня | M1 робить **тільки середньовічний**. Вогнепальний — лише після підтвердження ядра. Один код бою, різні дані |
| **Загадки фруструють** | 🟠 середня | Силовий шлях завжди доступний; складність видно до початку; режим «спрощені замки» |
| **Low poly виглядає дешево** | 🟠 середня | Якість дає не полігонаж, а **світло й силует**: запечене освітлення, rim light, пласка насичена палітра, один акцентний колір на біом. Референс з дошки (літаючі руїни) саме такий |
| **Rollback + фізика = пекло детермінізму** | 🟠 середня | Нуль float, власна симуляція, консольні тести на кожен коміт |
| **Матчмейкінг 1v1 без гравців** | 🟠 середня | Боти на перші 5 матчів (чесно підписані), регіональні пули, приватні матчі по коду, обидва режими не роз'єднувати до M3 |
| **Wallhack-чит бачить суперника** | 🟡 | Прийнятний компроміс для 1v1 ([06](06-tech-and-netcode.md)), детектимо телеметрією |
| **Тематика «ГУЛАГ» = проблеми зі сторами** | 🟠 середня | Вигаданий «Сектор», нуль реальної символіки/прапорів/дат. Запасна назва напоготові |
| **Батарея й нагрів** | 🟡 | Режим 30 fps, запечене світло, термальний тест 20 хв як критерій приймання |

## Монетизація

Повністю в [09-economy-and-ranking.md](09-economy-and-ranking.md). Коротко: **тільки косметика**,
бойова пропускна на 6 тижнів, нуль павер-покупок, нуль лутбоксів з геймплейними предметами,
нуль інтерстішалів між матчами.

## Відкриті питання (відповісти до M1)

1. **Чи треба мінімапа?** Вона знижує напругу фог-ов-вору, але без неї гравець губиться.
   Гіпотеза: мінімапа показує **тільки відвідані** кімнати й ніколи — суперника.
2. **Скільки триває фаза наосліп?** 22 сек — це здогад. Тюниться плейтестом, це
   найважливіше число в грі.
3. **Чи падає лут суперника при нокауті?** Матч одноразовий, тож це питання тільки про
   те, чи можна «пограбувати» в раптовій смерті. Схиляюсь до «ні».
4. **Portrait — окрема черга?** Схиляюсь до «ні» (ліквідність), але міряємо win rate.
5. **Боти в звичайному матчмейкінгу при порожньому пулі?** Тільки якщо чесно підписані.
   Приховані боти — найшвидший спосіб втратити довіру спільноти.
