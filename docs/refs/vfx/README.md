# vfx — проєктувати ефект, дивлячись на нього

Ефект живе або помирає на **таймінгу й колірній кривій**, а не на кількості часток. І те, і
те можна спроєктувати тут, подивитися і виправити — **до того**, як щось авторується в Unity.

```
cd docs/refs/vfx && node shot.js      # пише hit.png — кадрову стрічку 0→300 мс
```

`preview.html` тримає ті самі числа, що підуть у `ParticleSystem`: тривалості шарів, криві
розміру, градієнти, кут конуса іскор, затримку кільця. Кожен шар у файлі — це одна система
часток у Unity.

Чого воно **не** перевіряє: справжній рендер Unity, сортування, освітлення, вартість на
телефоні. Воно перевіряє **задум** — і саме в задумі ефекти й провалюються.

## Навіщо це знадобилося

Перша версія удару мала: кільце більше за бійця, іскри морським їжаком на всі боки,
рожеві бульбашки замість уламків і 420 мс тривалості. Усе це було б відправлено в гру
наосліп. Три ітерації по скриншоту — і стало пристойно.

## Текстури

`make_textures.py` малює їх кодом, детерміновано:

| | що це і чому саме так |
|---|---|
| `core.png` | тверде ядро з короткою м'якістю. Не гаусів розмив: стилізований удар має читатись як **форма** на 1/8 екрана |
| `spark.png` | смуга, гостра в голові, сходить нанівець. Витягнута швидкістю, читається як **напрямок**, а не як розмазаність |
| `ring.png` | тонка оболонка. Каже «сила». Товсте кільце читається як бульбашка |
| `slash.png` | серп із вістрями на обох кінцях. Дуга клинка. Перша версія була товстим м'яким крилом — і виглядала як крило |
