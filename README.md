# Gulag Runners

**1v1 мобільний 3D-браулер з видом збоку, де ти спавнишся з голими кулаками.**

Два гравці на двох різних телефонах падають на випадкову арену без нічого. Зброя, аптечки
й броня лежать у скринях по арені — частина скринь відкривається миттєво, частина вимагає
швидкої логічної головоломки. Матч триває 2–3 хвилини. Переможець той, хто краще
конвертував час на лут у перевагу в бою.

> Робоча назва тематики: «Зона» — північна тайга, шахти, бараки, іржаве промислове залізо.
> Втікачі з таборів, які б'ються за припаси.

## Три речення, які тримають весь дизайн

1. **Лут — це не нагорода, це рішення.** Кожна секунда на скрині — секунда, яку
   суперник витрачає на те, щоб тебе знайти.
2. **Кулаки ніколи не бувають безнадійними.** Зброя має обмежений ресурс і повертає
   тебе до кулаків; кулаки б'ють найшвидше й паруються.
3. **Головоломка — це не блокування, а швидший шлях.** Будь-який замок можна зламати
   силою за 6 секунд; загадка займає 2–3 секунди. Ти платиш уважністю, не знаннями.
